1. 처리 정보와 목적

본인 SNS 계정의 연결과 계정 확인을 위해 플랫폼이 제공한 계정·채널 ID, 표시 이름, 사용자 이름, 동의한 권한 범위, 접근 토큰·갱신 토큰, 인증·만료 시각을 처리합니다. 작업과 오류 확인을 위한 상태·오류 코드도 관리합니다. SNS 비밀번호와 인증번호는 스튜디오가 수집하지 않습니다.

2. 처리 방식과 외부 서비스

사용자가 선택한 플랫폼의 공식 OAuth 로그인·토큰·프로필 또는 채널 API를 사용합니다. 인증 요청에 필요한 정보는 해당 Google/YouTube, TikTok, Meta/Instagram 서비스로 전송되며 해당 플랫폼의 개인정보처리방침도 적용됩니다. 이번 연결 기능은 다른 서비스의 비밀번호나 브라우저 쿠키를 가져와 인증에 사용하지 않습니다.

3. 저장과 보호

인증 토큰은 사용자가 운영하는 Studio 서버의 조직별 암호화 파일에 저장합니다. 앱 인증 설정은 서버의 비공개 설정에 저장합니다. 인증키·토큰을 프런트엔드, 일반 실행 로그, GitHub 소스나 공개 정책 페이지에 포함하지 않습니다. 다른 조직의 계정 정보를 조회하지 못하도록 권한을 검사합니다.

계정 정보와 토큰은 연결을 유지하는 목적이 있는 동안 보관합니다. 사용자는 해당 플랫폼의 연결 앱 설정에서 권한을 철회할 수 있고, 아래 문의처로 Studio에 남은 계정·토큰 기록 삭제를 요청할 수 있습니다. 현재 자동 연결 해제 버튼은 제공하지 않아 관리자가 요청을 확인해 처리합니다. 원본·완성 영상 및 상품 자료는 별도의 사용자 저장·삭제 요청에 따라 관리합니다.

유료 AI 제공업체를 이용한 미디어 처리는 별도 기능과 사용자가 승인한 범위에 따릅니다. SNS 인증 동의를 유료 생성·결제·추가 충전 승인으로 취급하지 않습니다. 계정 연결만으로 미디어 업로드나 댓글 발송을 자동 실행하지 않습니다.

사용자가 영상별 검수와 전송에 동의하면 선택한 플랫폼에 영상·제목·설명과 필요한 메타데이터를 전송하고, 전송 식별자·상태·파일 해시·실행 이력을 저장합니다. 전송 세션 주소도 서버에서 암호화 보관합니다. Instagram 미게시 보관함은 플랫폼 정책상 24시간 후 만료될 수 있으며 각 플랫폼의 보관 정책이 적용됩니다. Meta 통합 로그인의 필수 메시지 권한이 동의 범위에 포함될 수 있지만 현재 프로그램은 DM 조회·답장 API를 호출하지 않습니다.
